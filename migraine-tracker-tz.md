# Техническое описание и техническое задание
## Мобильное приложение: трекер мигрени (Android)

---

## 1. Техническое описание продукта

### 1.1 Суть продукта
Мобильное приложение для людей с мигренью и хроническими головными болями, позволяющее быстро фиксировать приступы, отслеживать динамику и триггеры, и формировать отчёт для врача.

### 1.2 Позиционирование
Не «ещё один комбайн для отслеживания здоровья», а узкоспециализированный, честный по монетизации инструмент. Ключевое отличие от крупных конкурентов (Migraine Buddy, CareClinic, Migraine Insight) — минимальное трение при логировании и отсутствие блокировки базовых функций (редактирование/удаление своих же записей) за подпиской.

**Примечание по конкурентному анализу (обновлено):** на рынке уже есть приложение с похожим набором фич (барометрическое давление, «режим приступа» с тёмным UI, честный ценник без подписки) — Migraine Diary: Headache Log от студии MyQuietSpot Inc. Однако у него минимальная база (100+ скачиваний, нет отзывов), это один из шести разноплановых шаблонных продуктов студии, и в его позиционировании есть слабое место: заявлена философия «privacy first» и «no ads», но в карточке приложения указано «Contains ads» — то есть реклама в бесплатной версии всё же есть за пределами самого приступа. Это расхождение между обещанием и реальностью — конкретная точка, где наш продукт должен быть последовательнее.

**Обновлённое ключевое отличие:** не просто «простой и честный», а **полностью без рекламы вообще, при любом сценарии использования**, плюс погодная/барометрическая корреляция — доступная уже на бесплатном уровне как основной, а не второстепенный дифференциатор (см. раздел 2.4 и 5).

### 1.3 Целевая аудитория
- Люди с диагностированной мигренью, ведущие дневник по рекомендации невролога
- Люди с частыми головными болями, ищущие закономерности (триггеры) самостоятельно
- Вторичная аудитория: пользователи, которым нужен PDF-отчёт перед визитом к врачу

### 1.4 Ключевые принципы продукта (не нарушать при разработке)
1. Запись приступа — максимум 2 тапа до сохранения. Все дополнительные поля — необязательны и сворачиваемы.
2. Бесплатный уровень должен быть полностью рабочим: логирование, просмотр истории, базовый график, базовая погодная корреляция — без ограничений по количеству записей и без пейволла на редактирование/удаление.
3. Платными могут быть только: экспорт в PDF, расширенная аналитика (тренды по дням недели/времени суток, эффективность медикаментов), расширенный экспорт данных.
4. Никаких модальных окон с призывом подписаться при попытке отредактировать или удалить существующую запись.
5. Данные — чувствительные медицинские данные; хранить с шифрованием, не передавать третьим лицам без явного согласия.
6. **Реклама не используется ни в каком виде и ни на каком уровне подписки** — ни баннеры, ни interstitial, ни в бесплатной версии. Это принципиальное отличие от конкурента, который заявляет «privacy first / no ads», но фактически показывает рекламу вне момента приступа. Нарушение этого принципа обесценивает всё остальное позиционирование продукта.

## 2. Функциональные требования (MVP)

### 2.1 Быстрое логирование приступа
**Основной сценарий (2 тапа):**
- Тап 1: кнопка «Приступ сейчас» на главном экране
- Тап 2: выбор интенсивности боли по шкале 1–10 (крупные тап-зоны, не слайдер с точным вводом)
- Запись сохраняется автоматически с текущим временем

**Расширенные поля (опционально, скрыты за «Добавить детали»):**
- Локализация боли (схема головы, тап по зоне)
- Симптомы: тошнота, светобоязнь, звукобоязнь, аура (мультивыбор чипсами)
- Принятые медикаменты (из пользовательского списка препаратов)
- Заметка (свободный текст)
- Возможные триггеры (стресс, сон, еда, гормональный цикл — мультивыбор)

**Требование:** приложение должно позволять сохранить запись с одним полем (интенсивность) и вернуться позже, чтобы дозаполнить детали.

### 2.2 Редактирование и удаление записей
- Полный доступ к редактированию/удалению любой записи из бесплатного уровня, без ограничений и без промо-попапов
- История изменений не обязательна для MVP

### 2.3 История и график
- Список всех приступов (лента, сортировка по дате)
- Базовый график: количество приступов и средняя интенсивность по неделям/месяцам — доступен бесплатно
- Фильтр по периоду (неделя / месяц / 3 месяца / всё время)

### 2.4 Экран «Статистика/Инсайты» (частично платный)

**Обновлено:** погодная/барометрическая корреляция переведена в бесплатный уровень. На рынке уже есть конкурент, который использует именно эту фичу как основной платный дифференциатор — но с минимальным тракшеном (100+ скачиваний, без отзывов). Открытие этой фичи бесплатно — способ забрать этот дифференциатор себе на старте и конкурировать не ценой фичи, а качеством исполнения и охватом аудитории.

Бесплатно:
- Общее количество приступов за период
- Средняя интенсивность
- Самые частые отмеченные симптомы/триггеры (простой подсчёт частоты)
- **Барометрическая/погодная корреляция** — автоматическая фиксация атмосферного давления в момент приступа (через сенсор устройства или API погоды) и базовый график «давление ↔ частота приступов»
- Уведомление о резком изменении давления (опционально включаемое)

Платно (Premium):
- Расширенный анализ триггеров: автоматический подсчёт корреляции по каждому отмеченному триггеру («стресс — в 73% тяжёлых приступов»), а не просто список
- Эффективность медикаментов: сравнение препаратов по среднему снижению интенсивности боли
- Корреляция с гормональным циклом (если пользователь включил модуль цикла)
- Расширенные тренды (день недели, время суток, сезонность)
- PDF-отчёт для врача (см. 2.5)

### 2.5 PDF-отчёт для врача (платно)
- Генерация PDF за выбранный период: список приступов, интенсивность, симптомы, медикаменты, графики
- Локальная генерация на устройстве (не через сервер, чтобы не хранить медданные на бэкенде)
- Возможность отправить/сохранить через системный share-диалог Android

### 2.6 Список медикаментов
- Пользователь ведёт свой список препаратов (название, дозировка)
- При логировании приступа выбирает препарат из списка одним тапом

### 2.7 Напоминания и уведомления (не критично для MVP, но желательно)
- Напоминание «отметить самочувствие», если приступов не было давно (опционально, отключаемо)
- Никаких push-уведомлений с призывом купить подписку

### 2.8 Онбординг
- Максимум 3 экрана
- Без обязательной регистрации для начала использования (регистрация — опционально, для синхронизации между устройствами)

## 3. Нефункциональные требования

| Категория | Требование |
|---|---|
| Офлайн-режим | Приложение должно полностью работать без интернета. Синхронизация (если есть аккаунт) — в фоне |
| Хранение данных | Локальная БД (Room/SQLite) как основной источник. Данные шифруются на устройстве |
| Приватность | Не собирать медицинские данные на сервере без явного opt-in. Политика конфиденциальности обязательна (требование Google Play для health-приложений) |
| Производительность | Открытие приложения и сохранение приступа — не дольше 1 секунды на устройствах среднего класса |
| Локализация | MVP — русский и английский языки минимум |
| Доступность | Крупные тап-зоны, поддержка увеличенного шрифта (важно: пользователь может логировать во время приступа при светобоязни — тёмная тема обязательна) |
| Тёмная тема | Обязательна с релиза — частый триггер мигрени это яркий экран |

## 4. Модель данных (укрупнённо)

**Attack (Приступ)**
- id
- timestamp_start
- timestamp_end (опционально)
- intensity (1–10)
- location_zones (список, опционально)
- symptoms (список тегов, опционально)
- triggers (список тегов, опционально)
- medications_taken (список ссылок на Medication)
- note (текст, опционально)

**Medication (Медикамент пользователя)**
- id
- name
- dosage
- created_at

**UserSettings**
- units (метрическая/др.)
- premium_status
- cycle_tracking_enabled (bool)
- reminders_enabled (bool)

## 5. Монетизация

**Принцип:** без рекламы вообще, ни на одном уровне. Это осознанный отход от модели ближайшего конкурента (Migraine Diary: Headache Log), у которого заявлен «no ads»/«privacy first», но фактически стоит пометка «Contains ads» в карточке приложения. Последовательность в этом вопросе — часть доверия, которое критично для медицинского дневника.

- **Free:** неограниченное логирование, редактирование, удаление, базовая история и графики, базовая погодная/барометрическая корреляция — без рекламы
- **Premium (разовая покупка $14.99–19.99 lifetime, без подписки):**
  - PDF-отчёт для врача
  - Расширенный анализ триггеров и эффективности медикаментов
  - Корреляция с циклом
  - Расширенные тренды (день недели/время суток/сезонность)

**Почему разовая покупка, а не подписка:** конкурент уже занял позицию «$14.99 once, no subscription» как явный контраргумент против годовых подписок других приложений (от $50+/год) — эта модель, судя по всему, резонирует с аудиторией мигреников, которые сами часто указывают на усталость от подписок в отзывах на приложения этой категории. Повторение той же ценовой модели — не копирование, а следование уже подтверждённому рыночному сигналу, при этом наш продукт выигрывает за счёт отсутствия рекламы и более широкого бесплатного уровня.

- Триал: не требуется в формате разовой покупки — вместо этого чётко показать пользователю, что именно входит в Premium, ещё до оплаты (например, отдельный экран с демонстрацией расширенной аналитики на примере данных)

## 6. Технологический стек (рекомендация для соло-разработчика)

- **Платформа:** Android нативно, Kotlin + Jetpack Compose (быстрее для соло-разработчика, чем кроссплатформенные фреймворки, если целевая платформа только Android)
- **Локальная БД:** Room
- **График/визуализация:** Vico или MPAndroidChart
- **PDF-генерация:** Android PdfDocument API (локально, без сервера)
- **Погодные данные (теперь бесплатная фича):** OpenWeatherMap API или аналог с бесплатным тарифом — учесть лимиты бесплатного тарифа API при планировании нагрузки, если фича доступна всем пользователям с первого дня
- **Аналитика использования:** минимальная, privacy-friendly (например, самостоятельный подсчёт событий без сторонних SDK, либо Firebase Analytics с анонимизацией)
- **Подписки:** Google Play Billing Library

## 7. Экраны (укрупнённый список)

1. Онбординг (2–3 экрана)
2. Главный экран (кнопка «Приступ сейчас», сводка за неделю)
3. Экран быстрого логирования (интенсивность + «Добавить детали»)
4. Экран деталей приступа (расширенные поля)
5. История приступов (лента)
6. Экран одного приступа (просмотр/редактирование/удаление)
7. Статистика/Инсайты
8. Список медикаментов
9. Настройки (тема, единицы измерения, напоминания, управление подпиской)
10. Экран Premium (пейвол только здесь, никогда не как попап поверх других действий)
11. Генерация/просмотр PDF-отчёта

## 8. Критерии готовности MVP (Definition of Done)

- [ ] Логирование приступа занимает не более 2 тапов в счастливом пути
- [ ] Редактирование и удаление записи работают без каких-либо пейволлов и попапов
- [ ] Бесплатный уровень функционален без ограничений по количеству записей
- [ ] Приложение полностью работает офлайн
- [ ] Тёмная тема реализована и включена по умолчанию при системной тёмной теме
- [ ] PDF-отчёт генерируется корректно и локально, без отправки данных на сервер
- [ ] Политика конфиденциальности опубликована и соответствует требованиям Google Play для health-приложений
- [ ] Протестировано на минимум 2 устройствах разных производителей (баги ввода текста — частая жалоба у конкурентов)

## 9. Метрики успеха после запуска

- Retention Day 7 / Day 30 (ключевая метрика для приложений-дневников)
- Конверсия в Premium (целевой ориентир для ниши: 3–7%)
- Средний рейтинг в Google Play (цель: выше 4.5 — конкуренты в основном 3.1–4.4 из-за жалоб на монетизацию)
- Доля пользователей, завершающих запись за один сеанс без выхода из приложения

## 11. Открытые вопросы и бэклог (не блокируют MVP)

Задачи, которые всплыли в процессе разработки, но не относятся к текущему этапу дорожной карты — чтобы не потерялись, но и не мешали основному плану.

- [ ] **Локализация v1.3+: исследовать, на какие языки переводить после RU/EN.** Не ориентироваться на распространённость мигрени по странам/национальностям — она не сильно различается в мире (~10–15% населения почти везде) и потому слабо дифференцирует выбор. Вместо этого смотреть на: объём и платёжеспособность аудитории Google Play на языке в целевых регионах, долю пользователей без комфортного английского, языковой состав отзывов у конкурентов (Migraine Buddy, CareClinic, Migraine Diary). Предварительные кандидаты для проверки данными (гипотеза, не решение): испанский, португальский (Бразилия), хинди/урду.
